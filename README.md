## Site Structure

Key routes and their sources:

| Path                 | Source                           | Purpose                                                                                             |
| -------------------- | -------------------------------- | --------------------------------------------------------------------------------------------------- |
| `/`                  | `src/pages/index.astro`          | Homepage: thesis hero, measurement outcomes, capabilities grid, selected work, and applied AI scope |
| `/about/`            | `src/pages/about.mdx`            | Professional profile: research, industry, software, appointments, and how to work with me           |
| `/posts/`            | `src/pages/posts.astro`          | Blog index with tag filter and Pagefind full-text search                                            |
| `/blog/[...slug]/`   | `src/pages/blog/[...slug].astro` | Individual blog posts                                                                               |
| `/publications/`     | `src/pages/publications.astro`   | Publications grouped by research theme                                                              |
| `/projects/`         | `src/pages/projects.astro`       | Project index — public open-source (MassFlow, MSMCP, PySharpe) and proprietary (MassPilot) cards    |
| `/contact/`          | `src/pages/contact.mdx`          | Contact links and availability                                                                      |
| `/sitemap-index.xml` | generated by `@astrojs/sitemap`  | Crawler sitemap; `public/robots.txt` points crawlers at `https://ericjanusson.ca/sitemap-index.xml` |

> **Content & collections:** The About page holds a short, evidence-linked career record
> that `audit-facts.mjs` checks alongside `claim-register.json`. Content collections
> in `src/content.config.ts` are `blog` and `publications` (the legacy empty
> `case-studies` collection was removed). Blog posts are published from MDX files
> in `src/content/blog/` (moving reviewed drafts from the gitignored `drafts/`
> directory when ready; the filename's date prefix is only a sorting aid—`date`
> in frontmatter is authoritative), and the `/posts/` nav link appears automatically
> whenever `blog` is non-empty.

## Development

Requires Node 24 (see `.github/workflows/astro.yml`).

| Command                 | What it does                                                         |
| ----------------------- | -------------------------------------------------------------------- |
| `make dev`              | Astro dev server                                                     |
| `make preview`          | Serve the production build locally                                   |
| `make build`            | Production build to `dist/`, then Pagefind indexing                  |
| `make check`            | `astro check` + Prettier + Vitest + `audit-facts.mjs` (what CI runs) |
| `make test`             | Unit tests only (Vitest)                                             |
| `make format-fix`       | Apply Prettier                                                       |
| `make responsive-check` | Verify mobile/desktop layouts across viewports via headless Chromium |

CI runs `make check` before `npm run build` on pull requests and pushes to
`main`, and deploys `dist/` to GitHub Pages on `main` pushes and manual
dispatches (see `.github/workflows/astro.yml`). Run `make check` before
`npm run build` locally, as a build alone does not run checks. Make's
`node_modules/.install-stamp` prerequisite may invoke `npm install` even after
`npm ci` unless the stamp file is present.

## Conventions

- **Icons** — no icon font. `src/data/icons.ts` holds every path; render with
  `<Icon name="…" />` (`src/components/Icon.astro`). Brand marks use Simple
  Icons (CC0); the rest are hand-drawn 24×24 strokes. `Domain.icon` and
  `ContactLink.icon` are typed as `IconName`, so a typo fails `astro check`.
- **Fonts** — Inter and JetBrains Mono are self-hosted from
  `src/assets/fonts/` (variable, Latin + Latin-Ext). They are declared in
  `src/styles/fonts.css` and imported by `BaseLayout`, which also preloads the
  two Latin subsets. There are no Google Fonts requests at runtime.
- **Math** — KaTeX renders at build time via `remark-math` + `rehype-katex`.
  Its stylesheet is ~30 KB, so `BaseLayout` only links it when a page passes
  `math`; `src/pages/blog/[...slug].astro` sets that flag by scanning the post
  body for `$…$`. In MDX, write bare `$…$` / `$$…$$` delimiters (a `{`…`}`
  escape is unnecessary and prevents `remark-math` from seeing the math).
- **Search** — Pagefind indexes only elements marked `data-pagefind-body`
  (currently the blog article wrapper), so site chrome stays out of results.
- **Facts** — `audit-facts.mjs` parses `src/pages/about.mdx`; run it after
  editing employment dates.
- **Publications** — `title`, `journal`, and `year` in
  `src/content/publications/*.mdx` are copied from the DOI record rather than
  rewritten (see the collection note in `src/content.config.ts`).
  `audit-facts.mjs` can only compare the site against itself, so
  `src/data/__tests__/publications.test.ts` pins entries that are easy to
  paraphrase; re-check any changed entry against its DOI.
