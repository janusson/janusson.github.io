## Site Structure

Key routes and their sources:

| Path                 | Source                           | Purpose                                                                                                      |
| -------------------- | -------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| `/`                  | `src/pages/index.astro`          | Homepage: name-first hero, selected work with measured outcomes, "What I Work On" grid, and contact channels |

## Development

Requires Node 24 (see `.github/workflows/astro.yml`).

| Command           | What it does                                                         |
| ----------------- | -------------------------------------------------------------------- |
| `make dev`        | Astro dev server                                                     |
| `make build`      | Production build to `dist/`, then Pagefind indexing                  |
| `make check`      | `astro check` + Prettier + Vitest + `audit-facts.mjs` (what CI runs) |
| `make test`       | Unit tests only (Vitest)                                             |
| `make format-fix` | Apply Prettier                                                       |

`make check` runs in CI before the build, so a green build locally implies the
same checks the deploy workflow enforces.

## Conventions

- **Icons** — no icon font. `src/data/icons.ts` holds every path; render with
  `<Icon name="…" />` (`src/components/Icon.astro`). Brand marks use Simple
  Icons (CC0); the rest are hand-drawn 24×24 strokes. `Domain.icon` and
  `ContactLink.icon` are typed as `IconName`, so a typo fails `astro check`.
- **Fonts** — Inter and JetBrains Mono are self-hosted from
  `src/assets/fonts/` (variable, Latin + Latin-Ext). They are declared in
  `src/styles/fonts.css` and imported by `BaseLayout`, which also preloads the
  two Latin subsets. There are no Google Fonts requests at runtime.
- **Math** — KaTeX renders at build time via `remark-math` + `rehype-katex`.
  Its stylesheet is ~30 KB, so `BaseLayout` only links it when a page passes
  `math`; `src/pages/blog/[...slug].astro` sets that flag by scanning the post
  body for `$…$`. In MDX, write bare `$…$` / `$$…$$` delimiters (a `{`…`}`
  escape is unnecessary and prevents `remark-math` from seeing the math).
- **Search** — Pagefind indexes only elements marked `data-pagefind-body`
  (currently the blog article wrapper), so site chrome stays out of results.
- **Facts** — `audit-facts.mjs` parses `src/pages/about.mdx`; run it after
  editing employment dates.
- **Publications** — `title`, `journal`, and `year` in
  `src/content/publications/*.mdx` are copied from the DOI record rather than
  rewritten (see the collection note in `src/content.config.ts`).
  `audit-facts.mjs` can only compare the site against itself, so
  `src/data/__tests__/publications.test.ts` pins entries that are easy to
  paraphrase; re-check any changed entry against its DOI.
